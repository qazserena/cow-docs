# 14 Portal Events

The portal (official site) complements the game client: more focus on **markets, events, mining, and claiming assets**.\
Route names below are common paths — follow the live menu.

## Ranch entry & intro

* **`/rangeland`**: game intro, enter game, weekly boards for milk / breeding / contribution, etc.

***

## Limited boxes & marts

| Page              | Content                                                                                   |
| ----------------- | ----------------------------------------------------------------------------------------- |
| **`/IGO`**        | IGO Genesis boxes: buy with USDT; whitelist price is lower; open for cattle or item packs |
| **`/CattleMart`** | Cattle mart / stargazing: buy boxes, shard craft, etc. (Halo-series play)                 |

Note: some boxes **can only be opened in-game** — the page will say so.

***

## Mining / staking

| Page                                               | Content                                   |
| -------------------------------------------------- | ----------------------------------------- |
| **Interstellar Mining** `/farm/interstellarmining` | Stake USDT to mine IRG, etc.              |
| **Year-End Staking** `/YearEndMining`              | Multi-period IRT / IRG dual-token staking |
| **Lazio Staking** `/LazioMining`                   | Stake IRT for LAZIO during event windows  |

Staking has lockups and APR configs — read rules and risks before acting.

***

## Airdrops & asset claims

| Page                                | Content                                                                        |

## Typical portal flow

1. Connect the same wallet address as in the game
2. Switch to the correct chain
3. Approve tokens / NFTs as the page prompts
4. Confirm the tx; arrival may be delayed
5. Return to the game client, refresh or re-login to see assets
