# Item List

A quick reference of common item types and what they’re for.\
Exact names, numbers, and sources follow the live game and current events.

## Growth consumables

| Type                  | Use                                 |
| --------------------- | ----------------------------------- |
| Normal forage         | Small vitality restore              |
| Mid forage            | Medium vitality restore             |
| High forage           | Large vitality restore              |
| Growth Boost Pack I   | Add growth points                   |
| Growth Boost Pack II  | Add more growth points              |
| Growth Boost Pack III | Can mature instantly                |
| Life Potion / HP pack | Extend Normal cattle life           |
| Rename Card           | Change nickname                     |
| Breed Card            | Extra breed counts (mostly Genesis) |

## Combat & competitive

| Type                  | Use                                       |
| --------------------- | ----------------------------------------- |
| Clear Ticket          | PVE wins / sweeps                         |
| Point Protection Card | Ladder rating protection                  |
| PVE Power Card        | Temporary combat 3-stat boost             |
| Shuffle Card          | Combat helper                             |
| Power Potion          | Big temporary boost in guild battle, etc. |
| Guardian Armor        | Guild battle Guardian buffs               |
| Battle background     | Change combat scene                       |

## Cosmetics & social

| Type                     | Use                   |
| ------------------------ | --------------------- |
| Avatar frame             | Profile display       |
| Skins / skin blind boxes | Combat look and stats |
| Badges / badge shards    | Milk hashrate         |

## Open-box & craft materials

| Type                      | Use                   |
| ------------------------- | --------------------- |
| Cattle blind box (embryo) | Open cattle or shards |
| Cattle shards             | Craft Normal cattle   |
| Skin blind box            | Open skins            |
| UR-series chests          | Mixed rewards         |
| Shard blind box           | Open cattle shards    |
| Limited packs             | Bundled items         |

## Source cheat sheet

| Channel                          | Common yields                                                  |
| -------------------------------- | -------------------------------------------------------------- |
| Academy shop                     | Forage, growth & combat items                                  |
| Guild shop                       | Clear Tickets, protection cards, limited boxes, armor, potions |
| Arena / quests / check-in / mail | Misc rewards                                                   |
| Portal IGO / mart / vouchers     | Boxes, voucher redemptions                                     |
| Market purchase                  | Finished NFTs / some tradable items                            |
