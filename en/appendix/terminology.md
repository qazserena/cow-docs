# Appendix · Glossary

| Term | Meaning |
|---|---|
| Legend Ranch | This game |
| CowGalaxy | The game universe; brand of the portal and forum |
| IRT / TIRT | Main token; T prefix = beta test token |
| IRG / TIRG | Game gold; T prefix = beta test token |
| Genesis cattle | Rare cattle NFT: eternal, stats at 100%, freely transferable and tradable |
| Normal cattle | Mainstream cattle NFT: finite lifespan, stats scaled by stars, marketplace-only trading (calves only) |
| Star multiplier | Share of base stats a Normal cattle actually gets: 0★ 25% → 3★ 80% |
| Base stats | Raw on-chain attributes; multiplied by the star multiplier for the displayed value |
| CowShed / Stable | Where cattle live and are raised; requires a bound planet |
| Farm level / Ranch level / Farm EXP | The 1 – 6 level shown as "Farm EXP" in the profile; expansion, breeding, raising, consumables add EXP; auto level-up; affects milk / combat multipliers and tech unlocks |
| Milk Factory | Stake cows for IRT; 200,000 IRT daily pool |
| Hashpower | Milk share weight = (Milk + Milk Rate) ÷ 2 × tech × farm multiplier, plus badge |
| Breeding Institute | Breeding, boxes, rentals |
| Rental | Paying to breed with someone's listed stud |
| Academy | Shop, expansion, star-up, tech tree |
| Star EXP | Accumulated remaining lifespan of material cattle; 30 / 45 / 60 days per star |
| Arena | PVE / Match / Ladders |
| Cattle energy | Fed in the shed; for raising, milk duration, breeding, charging the station |
| Combat energy | Entry resource at the energy station, 300 per match, cap 20,000 |
| Spirit | In-match card cost; 3 at start, refills and grows to 8, no item restores it |
| Valid wins | Daily wins tiered 10 / 15 / 20, times farm and team multipliers |
| Win chest | Yesterday's share of IRT (Match) / IRG (PVE) by weighted wins |
| Battle report | Submitting 10+ Match wins to the on-chain contract for the 10,000 IRT daily pool |
| Ladders | 5v5 ELO mode, weekly chests on Monday |
| Planet / Guild | Your organisation; cannot be changed by yourself after binding |
| Home / Frontier / Federation | Three planet types: 20% / 10% / mother's rate; only Home fights guild battles |
| Guild Battle / GVG | Weekly guardian showdown between Home guilds |
| Guardian | The guild BOSS unit in guild battle, 1,000,000 HP |
| Battle pool | 30% of tax; the stake looted by the guild battle winner |
| Loot benefits | What the leader distributes to members after winning a guild battle |
| Daily benefits | Normal tax the leader funds and distributes by rank ratio |
| Contribution | Accumulated tax paid to the guild |
| Rewards Center | Where all rewards are collected; tax-free and taxable pools; claims create on-chain orders |
| Locked | Rewards Center state while an on-chain order is pending; no new rewards can be received |
| Box / embryo box | NFT that opens into cattle or shards; odds in [16](../16-blind-box.md) |
| Cattle shards | 10 craft a Normal calf |
| N – UR chests | Fixed item + IRT bundles |
| Badge | Milk Factory hashpower NFT, Bronze → Master |
| Skin / Mecha Demon | Stat-boosting NFT; Mecha Demon is the crafted ultimate skin, 0 – 3★ |
| Bond | On-chain relationship after 200 intimacy from teaming; +20% team wins |
| Marquee | Server-wide announcement: maxed tech, guild battle crits / lethal blow |
| Gas | On-chain transaction fee |
| Approve | Letting a contract use your tokens or NFTs |
| Banker signature | Server signature required for certain on-chain rewards / vouchers (reports, benefits, join approval, beta packs) |
| Portal | cowgalaxy.com: marketplace, events, beta, social pages |
| IGO | Limited Genesis box sale |
| Halo Chest / CattleMart | Portal event boxes and shard merging |
| Voucher | Portal NFT redeemable for items / cattle |
| Beta invite points | Portal `/betaInvite` referral points, a mainnet airdrop weight |
| Valid invite | An invitee who completed a first in-game quest |
| BBS / Crypto Blog | Forum bbs.cowgalaxy.com |
