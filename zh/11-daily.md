# 11 日常玩法

把「每天上线能领的、能做的」放在这一章：签到、任务、邮件、奖励中心、排行榜。

## 签到

- 每天可签到一次  
- 奖励可能是代币或道具，由运营配置  
- 奖励通常进入 **奖励中心** 或邮件，需再点领取（有的要上链）  

入口：主界面侧栏「签到」。

---

## 任务

任务一般分：

| 页签 | 例子 |
|---|---|
| **个人任务** | PVE 扫荡、质押母牛、PVP/PVE 场次、扩栏、合成、繁育、租借挂单、牧场等级、喂养成牛、升星、科技满级等 |
| **公会任务** | 组队斗牛、5v5、缴税、建亲密关系、参加公会战等 |
| **每日 / 每周 / 成就 / 新手** | 按刷新周期归类 |

- 完成条件后点领取  
- 奖励进入奖励中心统一管理  
- 日常类任务通常按 UTC 0 点重置（以游戏提示为准）  

---

## 邮件

- 系统邮件、运营活动邮、补偿邮等  
- 可含附件：代币、道具、NFT 等  
- 支持一键领取（链上附件需钱包确认）  

带税附件领取时会走星球税收逻辑。

---

## 奖励中心

把分散来源的奖励汇总在一起，例如：

- 签到  
- 邮件附件  
- 斗牛场胜场宝箱 / 战报领奖  
- 公会福利  
- 任务奖励  

### 领取注意

1. 部分奖励点领取后还要 **钱包上链确认** 才到账  
2. 区分 **带税 / 免税**  
3. 网络拥堵时多等一会，不要反复狂点造成重复 Gas  

---

## 排行榜

| 榜单 | 说明 |
|---|---|
| 积分赛周榜 | 斗牛场积分赛，周期结算发奖 |
| 公会战积分榜 | 偏长期公会实力 |
| 公会战伤害周榜 | 进攻贡献 |
| 公会战回血周榜 | 治疗贡献 |

门户牧场介绍页也可能展示产奶 / 育种 / 贡献类周榜。

结算时间常见为每日 0 点、周榜周一（以实际为准）。

---

## 推荐的每日清单

1. 签到  
2. 清任务（个人 + 公会）  
3. 牛奶厂领取产奶  
4. 斗牛场打满关键场次 / 胜场宝箱  
5. 奖励中心全部领取  
6. 看公会是否有福利可领、公会战是否开战
