# 15 常见问题 FAQ

按「我遇到了什么现象」查找。仍解决不了时，保留截图、时间、钱包地址（勿发私钥）联系官方客服 / 社群管理员。

---

## 登录与账号

**连不上钱包 / 签名失败？**  
检查 MetaMask 是否解锁、网络是否正确、页面是否被浏览器拦截弹窗。

**提示异地登录 / 突然掉线？**  
同一账号只允许一处在线，别处登录会踢旧会话。

## 牛与牛栏

**为什么牛不能产奶 / 不能打架？**  
检查：是否成年、性别是否匹配、是否在栏内、体力是否足够、是否处于质押 / 战斗 / 上架 / 喂食 / CD / 死亡等冲突状态。

**普通牛死了？**  
寿命耗尽或长期缺照料会导致死亡销毁。平时用生命药剂续命，并保持入栏喂养。

**栏位不够？**  
去科技研究所扩容；清理死亡牛占用的栏位。

**农场等级 / 农场经验怎么升级？**  
没有单独升级按钮。扩栏、繁殖、把小牛养成成年、使用体力包 / 成长包 / 生命药剂都会加 **农场经验**；攒满当前档会自动升一级。查看入口：个人中心 →「农场经验」。升到 2 级需 200 经验（门户邀请 / 兑换常见门槛）。详见 [03 牛栏与养成](./03-cowshed-and-growth.md)。

## 产奶

**收益太少 / 为 0？**  
确认已质押成功、体力未耗尽、已点击领取；收益还受全服算力、自身属性、牧场等级、徽章、税率影响。

**领取后余额少了一截？**  
星球税收自动扣除，见 [08](./08-guild.md)。

## 战斗

**匹配不到人？**  
可能超时匹配机器人；或当前模式场次已用尽、能量不足。

**对局里提示「精神力不足」？**  
这是出牌用的蓝，不是牛栏体力，也不是能量站那条战斗能量。开局只有 **3** 点，轮到自己时上限 +1 并回满（最高 **8**）。卡面费用高于当前剩余精神力就出不去。局内 **没有道具可补精神力**，出便宜牌或结束回合等下一回合回满即可。详见 [07 斗牛场](./07-arena.md)。

**匹配赛怎么突然打到机器人？**  
点开始后约 **15 秒** 配不到合适对手，1v1 / 3v3 / 5v5 会用机器人补位。1v1 还会按牛的 **星级** 限制对手（创世只打创世）。积分赛不会补机器人。完整 PK 流程见 [07](./07-arena.md)。

**为什么不能进公会战？**  
需在会长选人名单内，且处于开战阶段；检查公会是否已报名。

## 公会福利

**会长发了每日福利，自己看不到？**  
会长不参与每日福利分配，属正常。

**成员也看不到？**  
确认已成功「发放」、未过期、对方非当日入会、对方职位有分配额度。

**掠夺福利领不了？**  
需本周公会战胜利且会长已发放；未胜利会提示无奖励。

## 配种

**配不了？**  
检查次数、CD、体力、费用余额、状态；借配还需挂单方牛仍可用。

**开盒没出创世？**  
配种牛牛盲盒开出创世的初始概率是 **0.01%（万分之一）**，连开很多次仍全是普通小牛或碎片属于正常。各类盒子的完整掉落表见 [16 盲盒开奖公示](./16-blind-box.md)。

## 领取与链上

**奖励中心点了但钱包没到账？**  
许多奖励需二次上链确认；查看交易是否成功、网络是否正确、是否还在等待打包。

**Gas 失败 / 卡住？**  
提高 Gas 或等待拥堵缓解；不要用不同参数重复提交多笔。

**授权之后很危险吗？**  
只授权官方合约；定期在区块链浏览器检查授权并撤销不明授权。

## 市场

**搜不到某头牛？**  
可能已下架、死亡过滤、筛选条件过严、网络错误。

**为什么有的牛有「出售」，有的没有？**  
**普通成年牛不能挂到 NFT 市场**（链上规则）。只有 **普通小牛** 和 **创世牛牛** 可以出售。成年普通牛详情页仍可 **转移**，只是没有出售按钮。详见 [13 NFT 交易市场](./13-market.md)。

**上架失败？**  
未授权、普通成年牛不可售、**小牛 USDT 定价低于 150**、质押/战斗等冲突状态、余额不足付 Gas、网络错误。
