## 游戏一句话介绍

传奇牧场是一款围绕 **牛牛 NFT** 展开的链游：

1. 用钱包登录，进入一个星球公会  
2. 开盲盒或市场买入获得牛牛（公测期直接领开服礼包）  
3. 把牛放进牛栏喂养长大  
4. **母牛**去牛奶厂产奶挖 **IRT**，**公牛**去斗牛场打架赚 **IRG / IRT**  
5. 配种繁殖、升星、点科技树变强  
6. 参加公会与公会战，领税收福利  

资产（牛、盲盒、皮肤、徽章、星球、道具、头像）都是链上 NFT / 代币，大多可在市场流通。

## 背景故事（可选阅读）

在牛宇宙（CowGalaxy）中，牛牛因信仰不同组成两大星际联邦——**银河帝国**与**探索者星盟**。  
星球分为家园星球、联邦星球、拓荒星球三类。玩家在星球上建牧场、养牛牛、征战，争夺资源与荣誉。
