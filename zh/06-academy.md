# 06 科技研究所

科技研究所（界面文案也可能写作学院 / Academy）做四件事：

1. **道具商店** — 买草料与养成 / 战斗道具  
2. **扩容牛栏** — 增加栏位  
3. **合成升星 / 碎片合成** — 强化普通牛或合成新牛  
4. **科技系统** — 用 IRT 研发 9 项永久加成  

---

## 道具商店

| 商品 | 价格 | 库存模式 |
|---|---|---|
| 普通 / 中级 / 高级草料 | 100 / 200 / 300 IRG | 固定库存，售罄由运营补货 |
| 普通 / 中级 / 高级成长加速包 | 100 / 200 / 300 IRT | 每日限量 50 个 |
| 普通 / 中级 / 高级体力包 | 100 / 200 / 300 IRT | 每日限量 50 个 |
| 普通 / 中级 / 高级生命药剂 | 4000 / 8000 / 12000 IRT | 每日限量 50 个 |
| 改名卡 | 300 IRT | 固定库存 |

- 商品名旁的 **剩余 N** 是全服共享库存，不是你个人的购买次数  
- 每日限量商品 **北京时间 0 点** 自动补满；剩余为 0 时按钮置灰，次日再买  
- 单次购买数量不能超过当前剩余；买完去 **背包** 使用  

通关卡、积分保护卡、洗牌卡、战力卡、繁殖卡、牛牛碎片等在 **公会商店**（见 [08](./08-guild.md)）。

## 扩容牛栏

初始 2 格，最多 16 格；价格 500 → 3200 IRT 递增，每格给 50 ～ 180 农场经验。价格表见 [03](./03-cowshed-and-growth.md)。

## 合成升星（普通成年牛）

仅 **普通成年牛** 可升星，0 → 3 星（创世牛无星级，属性本就 100% 生效）。

### 为什么要升星

普通牛的属性按星级系数生效：**0 星 25% → 1 星 40% → 2 星 60% → 3 星 80%**。产奶、战斗都按这个数算，升一星通常比换一头牛划算。

### 怎么升

1. 选一头在栏内的 **主体牛**（普通、成年、未满 3 星）  
2. 选若干头 **材料牛**（普通、成年、未死亡、你名下，可在栏内或钱包）  
3. 支付 IRT 手续费（可调），确认  

- 材料牛会被 **销毁**；它的 **剩余寿命** 全部转成主体牛的「升星经验」  
- 升星经验累计到 **30 天** 升 1 星、再 **45 天** 升 2 星、再 **60 天** 升 3 星；多余经验保留，一次喂够可以连升  
- 所以刚成年、寿命还长的材料牛最「值钱」；界面会提示经验溢出风险  
- 升星时主体牛的 **寿命重置为满值**（且至少 30 天）——这是普通牛续命的重要手段  

操作前请确认材料牛可以牺牲。

### 碎片合成

**牛牛碎片 ×10 → 1 头普通小牛**（随机性别，属性 4000 ～ 5000 底值），在合成界面操作，不收 IRT。

## 科技系统

用 IRT 给单项科技「研发」（1 IRT = 1 经验），累计投入到档就升级，每项 0 ～ 5 级：

| 等级 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 累计投入 IRT | 100 | 250 | 450 | 700 | 1000 |

9 项全满共 9000 IRT。满级一项会全服跑马灯通报，并有成就任务奖励 10000 IRG。

### 九项科技（名称以游戏内为准）

| 系 | 科技 | 1 ～ 5 级效果 | 解锁牧场等级 |
|---|---|---|---|
| 繁殖 | 精打细算 | 繁殖费用 ×95% / 90% / 80% / 70% / **50%** | 2 |
| 繁殖 | 极速恢复 | 繁殖 CD −3h / −7h / −12h / −18h / **−24h** | 4 |
| 产奶 | 催奶剂 | 产奶量 +2% / 5% / 9% / 14% / **20%** | 2 |
| 产奶 | 产奶套装 | 产奶效率 +2% / 5% / 9% / 14% / **20%** | 4 |
| 产奶 | 科学化生产 | 质押体力消耗 −2% / 5% / 9% / 14% / **20%** | 6 |
| 战斗 | 强心剂 | 开战生命 +1% / 2.5% / 4.5% / 7% / **10%** | 2 |
| 战斗 | 现代化武器 | 开战攻击 +1% / 2.5% / 4.5% / 7% / **10%** | 6 |
| 战斗 | 金刚不坏 | 开战防御 +1% / 2.5% / 4.5% / 7% / **10%** | 4 |
| 战斗 | 事半功倍 | 每场能量消耗 −4% / 8% / 12% / 16% / **20%** | 4 |

牧场等级不够时节点锁定，显示「牧场等级达到 N 级解锁」。支持「一键升级」批量投入。

## 建议加点思路

| 主玩法 | 优先 |
|---|---|
| 产奶矿工 | 催奶剂 → 产奶套装 → 科学化生产 |
| 斗牛竞技 | 现代化武器 / 强心剂 → 金刚不坏 → 事半功倍 |
| 专职繁殖 | 精打细算（省一半配种费）→ 极速恢复 |
| 均衡发展 | 先点对你当前瓶颈帮助最大的 1 ～ 2 项 |
