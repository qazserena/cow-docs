# 17 公测指南 · 礼包 · 邀请积分 · 空投

**公测时间：2026 年 10 月 1 日 — 12 月 31 日**，跑在 Sepolia 测试网，全部玩法免费开放。

公测最重要的事是把问题找出来：你的每一次游玩、每一条反馈都会被记录，作为主网空投的依据。门户「公测」菜单按动线排好了四步：**看规则 → 领资产 → 邀请 → 反馈**。

---

## 1. 领取公测资产（门户 `/betaAssets`）

连接钱包并签名登录后，有两档可领。领取由官方签发凭证（10 分钟有效）再上链，一笔交易全部到账。

### 开服礼包（每个钱包一次）

把每条玩法的门都推开：

| 资产 | 数量 | 用来 |
|---|---|---|
| 家园星球卡 | 1 | 直接建公会当会长，可直接报名公会战（人口 10,000、税率 20%，见 [08](./08-guild.md)） |
| 创世牛 | 1 | 高属性、永恒寿命、可交易 |
| 成年公牛 / 成年母牛 | 各 1 | 公牛打斗牛场、母牛产奶，两头可直接配种 |
| 普通小牛 | 1 | 体验喂养 → 成年链路 |
| 牛牛盲盒 | 1 | 去育种研究所开 |
| 普通 / 中级 / 高级草料 | 各 10 | 喂养 |
| 普通 / 中级 / 高级成长加速包 | 各 3 | 催熟小牛 |
| 普通 / 中级 / 高级体力包 | 各 3 | 补体力 / 充战斗能量 |
| 普通 / 中级 / 高级生命药剂 | 各 1 | 普通牛续命 |
| TIRT | 2000 | 扩栏、科技、配种启动资金 |
| TIRG | 20000 | 买草料 |

礼包不保证「够玩多久」，后续靠游戏内循环（产奶、胜场宝箱、任务）自给自足。

### 每日补给（每 24 小时一次）

| 资产 | 数量 |
|---|---|
| 普通 / 中级 / 高级草料 | 各 10 |
| 普通 / 中级 / 高级体力包 | 各 2 |
| TIRG | 2000 |

只发消耗品、不发 NFT 和 TIRT，避免小号刷量影响空投公平。领取条件：

- 已经 **进过一次游戏**（钱包在游戏里登录过）  
- 在游戏里 **完成过至少一个任务**（质押母牛、打几场 PVE 这种真实玩法都算）  
- 同一网络下短时间内领取的钱包数量有上限，批量开小号会被挡住  

按钮置灰时页面会说明原因：先进游戏 / 先完成任务 / 冷却中 / 库存不足（等运营补货）。

## 2. 邀请赚积分（门户 `/betaInvite`）

每个地址有一个 **12 位邀请码** 和专属链接（首次打开页面自动生成，终身不变）。好友通过你的链接进站或填码绑定后，你们的积分按下面规则累计。**积分是主网空投的核心权重之一**。

### 积分规则

| 事件 | 谁得分 | 积分 |
|---|---|---|
| 填码绑定成功 | 被邀请人 | +30 |
| 好友绑定了你 | 邀请人 | +20 |
| 好友进入游戏 | 邀请人 | +50 |
| 好友完成首个游戏任务（= **有效邀请**） | 邀请人 | +100 |
| 有效邀请达 5 / 10 / 25 / 50 / 100 人 | 邀请人 | +200 / +500 / +1500 / +4000 / +10000 |

一个完整转化的好友值 170 分，里程碑另计。

### 等级（纯展示，不参与空投结算）

| 等级 | 称号 | 积分门槛 |
|---|---|---|
| Lv1 | 小牛犊 | 0 |
| Lv2 | 牧场主 | 300 |
| Lv3 | 牧群首领 | 1,200 |
| Lv4 | 牧场大亨 | 3,000 |
| Lv5 | 星际拓荒者 | 8,000 |
| Lv6 | 银河传奇 | 20,000 |
| Lv7 | 星河之主 | 50,000 |

### 规则与反作弊

- 每个地址 **只能绑定一次** 邀请人，绑定后不可更改；不能填自己的码，不能反向绑定邀请过你的人  
- 被邀请人的网络与邀请人 30 天内用过的网络相同、或同一网络 30 天内已有 3 个计分绑定 → 关系照常记录，但 **双方都不计分**（页面会标「不计分」）  
- 积分只来自测试网上的真实游玩；机器人、脚本、批量小号会被剔除并可能扣分  
- 排行榜展示 Top 50（同分先到先得），约每分钟刷新；页面有邀请海报与一键分享到 X

## 3. 空投规则（门户 `/beta`）

公测期间不发放任何代币。三个月的贡献会在 **主网上线时** 统一折算发放（代币 + 游戏道具），按三个维度：

| 维度 | 看什么 |
|---|---|
| **问题反馈** | 被采纳的问题数量与严重程度，同一问题以首个有效反馈为准；有价值的玩法 / 平衡性建议同样算 |
| **交互数据** | 养成、产奶、竞技、公会战、交易等行为的广度与持续度，不是某一项刷出来的次数 |
| **社区贡献** | 论坛发帖与回复、帮助其他玩家、攻略与内容创作 |

邀请积分与以上三项并列。最终权重、比例与名单在发放前通过官方公告公布。

## 4. 反馈与社区（论坛 bbs.cowgalaxy.com）

论坛用钱包签名登录，与游戏同一地址。分类：

| 分类 | 说明 |
|---|---|
| 游戏讨论 | 玩法交流、攻略 |
| 游戏规划 | 对后续版本的建议 |
| **Bug 和问题反馈** | **只有你和管理员能看到**，防止有人照着 bug 帖钻空子；门户「反馈与社区」直达此分类发帖 |
| 其他 | — |

发 Bug 帖请写清：哪个界面、怎么复现、你的钱包地址（勿发私钥）。防刷：同一地址发帖间隔 30 秒、回复间隔 10 秒。

---

## 5. 几件需要先知道的事

- 公测跑在测试网上。测试期间获得的代币、牛牛、星球与道具 **都不会迁移到主网**，仅用于体验玩法  
- 为了打磨经济模型，公测期间可能随时调整数值、甚至重置部分数据，以当下公告为准  
- 脚本刷量、批量小号会被剔除出空投名单  
- 本章是阶段性说明，空投最终规则以主网上线前的官方公告为准
