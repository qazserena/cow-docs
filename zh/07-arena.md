# 07 斗牛场

斗牛场是 **成年公牛** 的战斗中心：回合制卡牌对战，可打 PVE、匹配赛与积分赛，赚 **IRG / IRT**、积分与宝箱奖励。

## 开战前准备

1. 成年 **公牛** 在栏内，状态可用  
2. 有足够 **战斗能量**（在能量站用体力或体力包充能；能量池有上限）  
3. 今日该模式场次未用尽  
4. 可选：穿戴皮肤、携带通关卡 / 战力卡 / 积分保护卡等  

---

## 三种模式

### 1）PVE（闯关）

- 挑战 BOSS / 关卡爬层  
- 可用 **通关卡** 扫荡（有每日次数限制）  
- 主要产出游戏币与胜场进度  

### 2）匹配赛（PVP）

- 支持 1v1、3v3、5v5  
- 可好友或公会频道邀请组队  
- 匹配超时可能匹配机器人补位  

### 3）积分赛（Ladders）

- 通常为 5v5  
- 使用 ELO 类积分，有周榜与发奖  
- 可用 **积分保护卡** 避免掉分（按道具说明）  

---

## 战斗怎么打（规则概要）

- **回合制卡牌**：掷骰等方式决定先手  
- 卡牌分战斗 / 防御 / 魔法等类型（大量成语命名卡牌）  
- **精神力（蓝）**：局内出牌资源，见下一节；不要和开战前的 **战斗能量**、牛栏 **体力** 搞混  
- 手牌上限有限；每回合最多出 **2** 张，且不能出两张同类型  
- 存在暴击、吸血、反弹、无敌、封印、眩晕等大量 Buff  
- 支持投降投票、断线重连；全员长时间断线可能终止对局  

更细的卡牌说明可在场内 **卡牌图鉴** 查看。

---

## 精神力（局内蓝条）

对局里每张牌都有费用。当前精神力不够那张牌的费用时，会提示 **「精神力不足」**，牌出不去。这是局内规则，不是坏了。

| 规则 | 说明 |
|---|---|
| 开局 | **3 / 3** |
| 己方回合开始 | 上限 **+1**，并 **回满** 到新上限 |
| 上限 | 最高 **8** |
| 怎么扣 | 打出卡牌，按卡面费用扣除（常见 1～6 点） |
| 怎么补 | **没有药品、没有能量站可给精神力充能**。只能等自己的下一回合回满 |
| 带不走 | 本回合没用完的点，下回合仍按上限回满，不会额外攒着 |

和另两条资源的区别：

- **体力**：牛栏喂养，给养成 / 产奶 / 给能量站充能用  
- **战斗能量**：开战前在能量站准备，不够会进不了斗牛场  
- **精神力**：已经进了战斗之后，用来出牌  

打法建议：前几回合只有 3～4 点时，先出 1～2 费牌；4 费、6 费牌等上限涨上来再打。本回合已经出过一张、剩下的蓝不够下一张时，换便宜牌或点「回合结束」。

## 一场 PK 怎么打完（服务端规则）

斗牛场所有模式共用同一套回合制引擎。下面按「匹配 → 进场 → 猜先 → 出牌攻击 → 分胜负」说明，数字来自当前游戏服实现。

### 1. 开战前要过的关

- 成年 **公牛**，链上战斗三维（攻 / 耐 / 防）有效、未死亡  
- 能量站 **战斗能量** 够扣：当前各模式入场消耗均为 **300**（模板可调）  
- 选好上场牛；组队模式还要人齐  

能量不够会进不了场（和局内精神力不是一回事）。PVE 战力卡、皮肤属性在进场时叠到这头牛上。

### 2. 三种模式怎么配上对手

| 模式 | 人数 | 怎么配 |
|---|---|---|
| **PVE 闯关** | 你 1 人 vs 关卡怪 | 按关卡表出怪，不匹配真人。你这边固定先手 |
| **匹配赛 1v1** | 2 人 | 找另一支已点「开始」的 1v1 队。**只和星级相邻的普通牛打**（0 星对 0～1，1 星对 0～2，2 星对 1～3，3 星对 2～3）；**创世牛只打创世牛** |
| **匹配赛 3v3 / 5v5** | 6 / 10 人 | 双方必须满编。站位进场时会打乱 |
| **积分赛** | 每边最多 5 人，凑满 5v5 | 把已就绪的小队按人数从大到小塞进红/蓝两方，直到两边都是 5 人 |

匹配赛点开始后若 **15 秒** 还没有合适对手：

- **1v1**：改打机器人（属性约为你这头牛三维各减 200～500，结算仍记成单人匹配赛）  
- **3v3 / 5v5**：用机器人补满对面；普通牛机器人三维约 5000±2000，创世约 10000±2000  

积分赛没有「超时补机器人」，人不够就继续等。

组队：队长建队、选牛、邀请或公会频道进队、满员后点开始。队长退队则整队解散；被踢或自己退出会取消匹配。

### 3. 场上站位

| 模式 | 站位 |
|---|---|
| PVE、1v1（含打机器人） | 各 1 头，站后排中 |
| 3v3、积分赛 | 各边后排上 / 中 / 下 3 格 |
| 5v5 | 前排 2 + 后排 3，共 5 格 |

己方全灭或对方全灭才分胜负（见第 6 节）。

### 4. 猜先、发牌、回合

1. 双方加载完成并点准备后 **猜先**：匹配赛 / 积分赛红蓝点数随机，点数大的先手；PVE 你这边固定先手。  
2. 开局每人洗一副完整卡组，先发 **3** 张。  
3. 先手队从第一回合开始行动。己方回合开始时精神力规则见上一节。  
4. **轮到某头牛行动**：再补牌（通常 2 张），手牌最多 **6**；牌堆抽空会重新洗入全部卡牌。  
5. 出牌限时约 **20 秒**，出手动画限时约 **8 秒**；超时服务器会自动跳过。  
6. 该牛打出本回合选中的牌效果后，发动 **一次普攻**（母牛在公会战里改为给守护者治疗，斗牛场上场的是公牛所以是普攻）。  
7. 本方所有存活的牛都行动完，换对面回合。

出牌限制（服务器会拒掉不合法操作）：

- 一张牌的费用不能高于当前精神力  
- 同一回合最多 **2** 张  
- 同一回合不能出两张 **同类型**（战斗 / 防御 / 魔法）  
- 被封印的类型本回合不能出  

机器人出牌：约 2.5～7 秒后随机出 0～2 张。

### 5. 伤害怎么算

普攻基础伤害（向下取整）：

**伤害 = ((0.5 × 攻击)² / (攻击 + 防御) × 0.8)**

攻击、防御会加上本回合卡牌和 Buff（加攻、加防、超体等）。常见修正：

- **无视防御**：改成大约「攻击 / 2」  
- **暴击**：按卡牌暴击率判定，再按暴击倍率加伤  
- **伤害加成 / 溅射 / 吸血 / 反弹**：按对应 Buff 百分比  
- **无敌**：这次打不掉血  

额外机制：

- **死神契约**：己方回合开始时，若生命过低，小概率触发（约 10%）  
- **超体**：本局累计消耗精神力达到 **10** 后，小概率触发一次（约 10%），大幅提高防御  

具体卡牌效果以场内图鉴为准。

### 6. 怎么算赢、投降、断线

每一头牛行动结束后检查：

- 对面全部倒下 → 你赢  
- 己方全部倒下 → 你输  
- 两边同时全灭 → **平局**  
- 本队投降投票通过 → 判负，对面赢  

投降通过所需同意人数随模式变化：1v1 自己点投降即生效；人多的模式要队内凑够同意票，反对票过多则这次投降失败。

断线：

- **全部人**断线超过约 **60 秒** → 对局强制结束  
- **部分人**断线约 **30 秒** → 服务器强制推进回合（相当于托管跳过）  
- PVE / 打机器人断线视为投降  
- 匹配赛 / 积分赛支持重连，重连后补发场面和手牌  

### 7. 积分赛分数

积分赛用 ELO：按你赛前积分 vs 对面人均积分结算。胜记 1.15 分、负记 0 分。K 值随分段：低于 1800 为 40，1800～2400 为 36.67，更高为 20。  

**平局**、或当日有效场次已满 **20** 场 → 积分不变。  
带了 **积分保护卡** 且本场会掉分 → 分数维持赛前。积分下限为 0。

### 8. 胜场怎么计奖励

每日胜场按档折算：未满 10 场不算档，10～14 按 10、15～19 按 15、20 及以上按 20。再乘牧场牛的收益系数。  

匹配赛里，3v3 / 5v5 胜场占比高时有组队加成（约 1.1 或全是 5v5 时约 1.2）；和 **亲密好友** 一起打还有额外加成。详见 [10](./10-social.md)。  

PVE 通关卡每日最多用 **2** 张（扫荡 / 推进关卡，以游戏内为准）；PVE 战力卡每日 **2** 张；积分保护卡每日 **1** 张。

---

## 奖励与每日限制

- 各模式每日有可打场次上限（如 PVP / PVE / 积分赛各自若干场，可调）  
- **胜场宝箱**：按当日胜场达到 10 / 15 / 20 等档位领取，高档位有奖励系数加成  
- PVP 战报在满足条件时可 **上链领奖**（需钱包确认，可能涉及 banker 签名流程）  
- 领取 IRT 类奖励时同样可能触发星球税收  

组队加成示例（以游戏内为准）：

- 高胜率五排等阵容可能有额外系数  
- 亲密好友组队可能有收益加成（见 [10](./10-social.md)）

## 新手战斗建议

1. 先打 PVE 熟悉卡牌与节奏；前几回合精神力少，先出低费牌  
2. 能量站保持能量充足，避免「有牛没能量」（这和局内精神力不是一回事）  
3. 每天清胜场宝箱档位  
4. 有稳定阵容后再冲积分赛
