# 10 好友与社交

## 好友

入口：主界面侧栏「好友」→ 好友管理（好友列表 / 添加好友 / 申请列表）。

1. 按昵称搜索玩家，发送申请（对方会收到提示）  
2. 对方在「申请列表」同意后成为好友；拒绝也会通知  
3. 好友卡片可：聊天、邀请组队、查看资料、建立亲密关系、删除  

好友列表显示对方最近在线时间、所属星球、亲密度。门户「社交 → 我的好友」可以查看同一份列表（添加 / 同意请在游戏内操作）。

## 聊天频道

| 频道 | 用途 |
|---|---|
| **公会聊天** | 本星球成员交流、组队、公会战指挥；联邦成员与母星共用 |
| **联邦频道** | 联邦星球内部交流 |
| **个人聊天** | 好友一对一，支持拉取历史记录 |

- 单条最多 **120** 个字符  
- 连发限制：连续 5 条后每秒恢复 1 条额度，过快会提示「重复的请求」  
- 敏感词会被替换成 `*`，不会拦截整条  
- 组队邀请会以消息形式出现在聊天 / 弹窗里，点同意即可进队

## 亲密关系（链上绑定）

四种关系（与性别无强制对应）：**密友、情侣、闺蜜、基友**。

### 怎么升级到可绑定

1. 与好友 **组队** 打 3v3 匹配赛、5v5 匹配赛或 5v5 积分赛，每局结算后同队好友之间亲密度 **+10**，输赢都算  
2. 亲密度达到 **200**（上限，到顶不再增加）后，可在「好友管理 → 亲密关系」里向对方发起绑定申请  
3. 双方同意后 **上链绑定**（需钱包确认，服务端签名；一对地址只能有一种关系）  

> 只有组队多人对战会涨亲密度：PVE、单人匹配赛、聊天、同公会都不计入。从 0 到 200 需要一起打 20 局。

### 绑定好处

- 和亲密好友同队赢下的匹配赛场次，折算胜场时额外 **+20%**（直接影响胜场宝箱与战报分成，见 [07](./07-arena.md)）  
- 公会成就任务「与公会成员建立亲密关系」奖励 1000 IRG + 高级体力包  
- 个人中心可展示关系  

### 解绑

任一方可在链上解除关系（钱包确认），解除后亲密度需重新累积才能再绑。

## 个人资料（个人中心）

点头像进入个人中心：

| 项目 | 说明 |
|---|---|
| 昵称 | **首次改名免费**，之后每次需先在背包使用一张 **改名卡**（300 IRT）；不能用标点，不能与当前重复，过敏感词 |
| 头像 / 头像框 | 可换成你持有的 **头像 NFT**（牛出生、成年时自动发放）；头像 NFT 转走后会被自动重置 |
| 个性签名 | 点击编辑，公开展示 |
| 农场经验 | 当前等级与进度，见 [03](./03-cowshed-and-growth.md) |
| 牛牛统计 | 公牛 / 母牛 / 创世 / 已繁殖 / 已死亡数量 |
| 收益统计 | 累计 IRT / IRG 收益 |
| 所属星球、亲密关系 | 点击可跳转 |

## 组队小贴士

- 匹配赛 3v3 / 5v5 可从好友列表或公会频道邀请；队长退出则整队解散  
- 公会任务常要求「与公会成员组队」，优先约同公会的好友  
- 亲密好友组队收益更优时，优先一起排  

相关任务见 [11](./11-daily.md)；战斗见 [07](./07-arena.md)
