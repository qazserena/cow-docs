# 02 代币与核心资产

## 两种游戏代币

| 代币 | 作用 |
|---|---|
| **IRT** | 主代币：配种、升星、科技、扩栏、买道具 / 皮肤、入会费、联邦申请、税收、产奶与战斗奖励 |
| **IRG** | 游戏金币：PVE 胜场宝箱与任务的主要产出；买草料、配种会消耗并销毁 |

公测期间两者分别叫 **TIRT / TIRG**（测试币），规则相同。部分门户活动会用到 **USDT**（IGO 购盒、星际挖矿、市场结算）。

### 怎么获得

| | IRT | IRG |
|---|---|---|
| 游戏内 | 牛奶厂产奶、匹配赛胜场宝箱、PVP 战报上链领奖、公会福利、积分赛周榜宝箱、任务 / 邮件 | PVE 胜场宝箱、任务（最常见）、宝箱 |
| 门户 | 年终质押、空投、公测礼包 | 星际挖矿（USDT 质押）、集市 FOMO 奖池、每日补给、空投 |
| 交易 | 客户端余额栏「IRT 兑换 / IRG 兑换」跳转 DEX | 同左 |

## 牛牛 NFT（最核心资产）

每头牛都是链上 NFT，是养成、产奶、战斗、繁殖的载体。

### 血统：创世牛 vs 普通牛

| | 创世牛 | 普通牛 |
|---|---|---|
| 获取 | 盲盒万分之一、IGO / 集市、公测礼包、市场购入 | 盲盒 90%、配种、碎片 ×10 合成、市场（仅小牛可上架） |
| 寿命 | **永恒**，不会死亡 | 有寿命，耗尽死亡销毁 |
| 星级 | 无星级，属性 **100%** 生效 | 0 ～ 3 星，属性按星级系数生效（见下） |
| 属性底值 | 8000 ～ 12000 | 小牛 4000 ～ 5000（有父母时参考父母）；活动 / 礼包成年牛 6000 ～ 8000 |
| 成长 | 出生即成年 | 需喂到 30000 成长值 |
| 繁殖 | 5 次 + 繁殖卡可无限追加 | 最多 5 次 |
| 转移与交易 | 钱包可自由转账，市场随时可卖 | **不能钱包直转**，只能经市场交易，且 **仅小牛可上架** |
| 续命 | 不需要也不能用生命药剂 | 生命药剂累计最多 +10 天 |
| 牛栏 | 创世公牛入栏后 24 小时内不能移出 | — |

### 性别决定玩法

| 性别 | 专属属性 | 主要玩法 |
|---|---|---|
| **公牛** | 攻击值、耐力值、防御值 | 斗牛场战斗、公会战进攻、给能量站充能 |
| **母牛** | 产奶量、产奶效率 | 牛奶厂质押产奶、公会战给守护者回血 |

通用属性：生命值（决定寿命长短）、体力值上限、成长值。

### 星级系数（普通牛必读）

普通牛面板显示和实际生效的属性，是底值乘以星级系数：

| 星级 | 0 星 | 1 星 | 2 星 | 3 星 | 创世 |
|---|---|---|---|---|---|
| 系数 | **25%** | 40% | 60% | 80% | 100% |

所以一头底值 4800 攻击的 0 星普通牛，实际只有 1200；升到 3 星是 3840。升星是普通牛变强的核心途径，见 [06](./06-academy.md)。

### 寿命

- 普通牛寿命 = **35 天 × 生命值 ÷ 10000**：小牛约 14 ～ 17 天，礼包成年牛约 21 ～ 28 天  
- 生命药剂每头牛累计最多续 **10 天**  
- **升星会把寿命重置为满值**（且至少 30 天），是普通牛「续命」的另一条路  
- 寿命到期即死亡；死亡牛仍占栏位，移出牛栏时销毁  

### 牛的状态（为什么点不了某个按钮）

空闲中、牛栏中、质押中、战斗中、喂食中、上架中、已死亡。

- 质押中的母牛要先赎回才能配种 / 移出  
- 喂食倒计时内（每个草料 10 ～ 20 分钟）不能同时做其他事  
- 配种后进入 3 天 CD（科技可缩短）

## 盲盒有哪些

| 类型 | 大概能开出什么 | 常见来源 |
|---|---|---|
| **牛牛盲盒（胚胎盒）** | 普通小牛 90%、碎片 9.99%（4 ～ 5 片）、创世牛 0.01% | 配种必得；推荐奖励；公测礼包 |
| **IGO 创世盲盒** | 创世 / 普通牛 / 道具礼包 / 皮肤礼包（奖池抽） | 门户限时 IGO（USDT） |
| **皮肤盲盒** | 5 款皮肤（30% / 30% / 15% / 15% / 10%） | 商店、公会商店、IGO 皮肤礼包、兑换券 |
| **N ～ UR 宝箱** | 固定道具包 + IRT，不是随机抽 | 积分赛周榜、活动 |
| **牛牛碎片盲盒** | 少量碎片 | 活动 |

完整件数与百分比见 **[16 盲盒开奖公示](./16-blind-box.md)**。**牛牛碎片 ×10** 可合成一头普通牛（见 [06](./06-academy.md)）。

## 其他常见链上资产

| 资产 | 说明 |
|---|---|
| **道具（ERC1155）** | 草料、成长包、体力包、生命药剂、改名卡、通关卡等，见 [12](./12-backpack.md) |

| **头像 NFT** | 牛出生 / 成年时自动发放，个人中心可换头像 |
| **兑换券 NFT** | 门户兑换券中心换草料、道具、皮肤盲盒等 |
