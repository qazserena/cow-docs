# 附录 · 道具清单

以下为游戏中常见道具类型汇总，方便查阅「这个道具是干什么的」。  
具体名称、数值、获取途径以游戏内与当期活动为准。

## 养成消耗

| 类型 | 用途 |
|---|---|
| 普通草料 | 少量补体力 |
| 中级草料 | 中量补体力 |
| 高级草料 | 大量补体力 |
| 成长加速包 I | 增加成长值 |
| 成长加速包 II | 增加更多成长值 |
| 成长加速包 III | 可直接成年 |
| 生命药剂 / 血量包 | 普通牛续命 |
| 改名卡 | 修改昵称 |
| 繁殖卡 | 增加可繁殖次数（多用于创世牛） |

## 战斗与竞技

| 类型 | 用途 |
|---|---|
| 通关卡 | PVE 胜场 / 扫荡 |
| 积分保护卡 | 积分赛掉分保护 |
| PVE 战力卡 | 临时提升战斗三维 |
| 洗牌卡 | 战斗辅助 |
| 战力药水 | 公会战等临时大幅加成 |
| 守护神铠甲 | 公会战守护者增益 |
| 战斗背景 | 更换战斗场景 |

## 外观与社交

| 类型 | 用途 |
|---|---|
| 头像框 | 个人展示 |
| 皮肤 / 皮肤盲盒 | 战斗形象与属性（皮肤盲盒几率见 [16](../16-blind-box.md)） |
| 徽章 / 徽章碎片 | 产奶算力 |

## 开盒与合成材料

| 类型 | 用途 |
|---|---|
| 牛牛盲盒（胚胎） | 开牛或碎片 |
| 牛牛碎片 | 合成普通牛 |
| 皮肤盲盒 | 开皮肤 |
| UR 系列宝箱 | 开综合奖励 |
| 碎片盲盒 | 开牛牛碎片 |
| 限时礼包 | 打包道具 |

## 获取渠道速查

| 渠道 | 常见产出 |
|---|---|
| 科技研究所商店 | 草料、养成与战斗道具 |
| 公会商店 | 通关卡、保护卡、限时盲盒、铠甲、药水 |
| 斗牛场 / 任务 / 签到 / 邮件 | 杂项奖励 |
| 门户 IGO / 集市 / 兑换券 | 盲盒、券兑道具 |
| 市场购买 | 直接买成品 NFT / 部分可交易道具 |
