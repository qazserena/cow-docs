# 附录 · 术语对照

| 术语 | 含义 |
|---|---|
| 传奇牧场 / Interstellar Rangeland | 本游戏名称（英文名 Interstellar Rangeland），牛宇宙 CowGalaxy 的第一款游戏 |
| 牛宇宙 / CowGalaxy | 游戏世界观所属宇宙，门户与论坛的品牌名 |
| IRT / TIRT | 主代币；T 前缀为公测测试币 |
| IRG / TIRG | 游戏金币；T 前缀为公测测试币 |
| 创世牛 | 永恒寿命、属性 100% 生效、可自由转账交易的稀有牛 NFT |
| 普通牛 | 有寿命、按星级系数生效、只能经市场交易（仅小牛）的主流牛 NFT |
| 星级系数 | 普通牛属性生效比例：0 星 25% → 3 星 80% |
| 底值 | 牛 NFT 链上记录的原始属性，乘星级系数后才是面板值 |
| 牛栏 / CowShed / Stable | 放置与养成牛的设施，入栏需已绑定星球 |
| 农场等级 / 牧场等级 / 农场经验 | 个人中心「农场经验」对应的 1 ～ 6 级；扩栏、繁殖、养成、用药加经验，满档自动升级；影响产奶 / 战斗系数与科技解锁 |
| 牛奶厂 / Factory | 质押母牛产奶挖 IRT，全服每日 20 万 IRT 池 |
| 算力 | 产奶分奖权重 = (产奶量 + 产奶效率) ÷ 2 × 科技 × 农场系数，加徽章 |
| 育种研究所 | 配种、开盒、借配 |
| 借配 | 付费租用别人挂单的牛配种 |
| 科技研究所 / Academy | 商店、扩栏、升星、科技树 |
| 升星经验 | 材料牛剩余寿命的累计，30 / 45 / 60 天升一星 |
| 斗牛场 / Arena | PVE / 匹配赛 / 积分赛 |
| 体力 | 牛栏喂养补充，用于养成、产奶时长、配种、给能量站充能 |
| 战斗能量 | 能量站里的入场资源，每场 300，上限 20000 |
| 精神力（蓝） | 对局内出牌费用；开局 3 点、己方回合回满且上限渐增至 8，无道具可补 |
| 有效胜场 | 每日胜场按 10 / 15 / 20 折档，再乘农场系数与组队加成 |
| 胜场宝箱 | 按昨日有效胜场占比分的 IRT（匹配赛）/ IRG（PVE）奖励 |
| 战报上链 | 匹配赛满 10 胜后提交到链上合约，分每日 10,000 IRT 池 |
| 积分赛 / 天梯 / Ladders | 5v5 ELO 积分赛，周一结算发宝箱 |
| 星球 / 公会 | 玩家所属组织，绑定后不可自行更换 |
| 家园 / 拓荒 / 联邦星球 | 三类星球：20% / 10% / 按母星 税率；只有家园能打公会战 |
| 公会战 / GVG | 家园公会间每周一次的守护者对抗 |
| 守护者 | 公会战中的公会 BOSS 单位，100 万血 |
| 战池 | 税收的 30%，公会战胜方掠夺的本金 |
| 掠夺福利 | 公会战胜利后会长分给成员的奖励 |
| 每日福利 | 会长从普通税收投入、按职位比例分给成员的奖励 |
| 贡献值 | 缴税累计的公会贡献 |
| 奖励中心 | 汇总领取各类奖励的界面，分免税 / 带税两池，领取生成链上订单 |
| 锁定状态 | 奖励中心有未完成的链上订单时的状态，期间不能领新奖励 |
| 盲盒 / 胚胎盒 | 开出牛或碎片的 NFT 盒；几率见 [16](../16-blind-box.md) |
| 牛牛碎片 | 10 片合成普通小牛 |
| N ～ UR 宝箱 | 固定内容的道具 + IRT 包 |
| 徽章 | 装在牛奶厂加算力的 NFT，青铜 → 大师六档 |
| 皮肤 / 机甲魔神 | 加战斗属性的 NFT；机甲魔神为合成的终极皮肤，可升 0 ～ 3 星 |
| 亲密关系 | 好友组队亲密度满 200 后链上绑定的关系，组队胜场 +20% |
| 跑马灯 | 全服公告：科技满级、公会战暴击 / 最后一击等 |
| Gas | 链上交易手续费 |
| 授权 / Approve | 允许合约动用你的代币或 NFT |
| Banker 签名 | 服务端签名后玩家才能领的链上奖励 / 凭证（战报、福利、入会审批、公测礼包） |
| 门户 / Portal | 官网 cowgalaxy.com：市场、活动、公测、社交页 |
| IGO | 限时创世盲盒发售 |
| 光轮宝箱 / 牛牛集市 | 门户集市活动的盲盒与碎片合成玩法 |
| 兑换券 | 门户用来兑换道具 / 牛的 NFT 券 |
| 公测邀请积分 | 门户 `/betaInvite` 的拉新积分，主网空投权重之一 |
| 有效邀请 | 被邀请人完成首个游戏任务 |
| BBS / 加密博客 | 论坛 bbs.cowgalaxy.com |
