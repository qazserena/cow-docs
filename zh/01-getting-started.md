# 01 新手入门

## 开始前你需要准备什么

1. **加密货币钱包**（推荐 MetaMask，桌面浏览器插件或手机 App）  
2. 钱包里有一点 **Gas 费对应的主链代币**（用于上链操作；测试网需领测试币）  
3. 能访问游戏客户端与门户官网的网络环境  

没有钱包？先安装 MetaMask → 创建钱包 → **务必备份助记词**（只保存在自己可控的地方）。

---

## 第一次进入游戏

### 1. 打开游戏并连接钱包

1. 打开传奇牧场游戏页面  
2. 点击连接钱包（MetaMask）  
3. 在钱包中确认连接与签名登录  

签名登录不会转账，只是证明「这个地址是你的」。同一账号在别处登录时，旧会话会被踢下线。

### 2. 选择语言

游戏支持简体中文、英语、繁体中文、韩语等。可在登录页或设置中切换。

### 3. 绑定星球公会（非常重要）

进入游戏后需要 **选择并绑定一个星球公会**：

- 绑定后 **不可更换**  
- 之后产奶、战斗领 IRT 收益时，会按该星球税率自动缴税  
- 税收计入你的公会贡献值  

选星球时建议：看税率（通常约 10%～20%）、公会活跃度、是否方便参加公会战。

### 4. 获得第一头牛

没有牛几乎玩不了核心玩法。入手方式：

| 方式 | 说明 |
|---|---|
| 开盲盒 | 育种研究所开牛牛盲盒；或门户 IGO / 集市活动开盒（几率见 [16](./16-blind-box.md)） |
| NFT 市场购买 | 门户交易市场买现成的 **小牛 / 创世牛**（普通成年牛不能上架，详见 [13](./13-market.md)） |
| 公测 / 活动领取 | 白名单用户可在门户「公测资产」等页面领取 |
| 好友推荐奖励 | 满足条件时推荐人可获得盲盒等奖励 |

### 5. 把牛放进牛栏

牛必须进入 **牛栏** 才能正常养成、繁殖、产奶、战斗。  
默认有少量栏位，不够可扩容（见 [03 牛栏与养成](./03-cowshed-and-growth.md)）。

### 6. 选择你的主线

| 你更想… | 建议路线 |
|---|---|
| 稳健产币 | 养 **母牛** → 牛奶厂质押产奶 |
| 战斗竞技 | 养 **公牛** → 斗牛场 PVE / PVP |
| 繁殖增值 | 凑齐公母牛 → 育种研究所配种开盒 |
| 社交公会 | 升职、缴税、参加公会战、领福利 |

多数玩家会三条线并行：一两头母牛产奶、一两头公牛打架、有余力再繁殖。

## 主界面大概长什么样

（名称以游戏内为准）

- **上方 / 角落**：代币余额（IRT、IRG）、头像进入个人中心  
- **场景建筑**：牛栏、牛奶厂、育种研究所、科技研究所、斗牛场、公会、交易市场等  
- **侧栏常用**：聊天、好友、任务、签到、背包、邮箱、奖励中心  

点建筑进对应玩法；点侧栏处理日常领取与社交。

---

## 新手推荐顺序（第一周）

1. 登录并绑定星球  
2. 至少得到 1～2 头牛并放入牛栏  
3. 喂草料，把小牛养到成年（或买成年牛）  
4. 顺手攒 **农场经验**（扩栏 / 繁殖 / 养成 / 用药），尽快升到 **2 级**（门户邀请与兑换常用门槛，见 [03](./03-cowshed-and-growth.md)）  
5. 母牛进牛奶厂开始产奶；公牛去斗牛场打几场 PVE 熟悉操作  
6. 每天签到、做任务、领奖励中心  
7. 了解公会福利与税率；有余力再学配种、升星、科技树  

---

## 测试网与正式环境

- **测试网**：资产无真实价值，用于体验  
- **正式环境**：资产有真实价值，操作前请确认网络、合约与金额  

切换网络、领测试币、白名单领取等，见门户说明或运营公告。

---

## 安全提醒

- 官方不会要你的助记词 / 私钥  
- 领奖、上架、开盒等需要钱包二次确认时，看清合约与金额再点同意  
- 钓鱼网站很常见：认准官方域名与公告渠道
