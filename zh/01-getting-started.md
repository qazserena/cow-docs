# 01 新手入门

## 开始前你需要准备什么

1. **加密货币钱包**：游戏客户端支持 MetaMask、TokenPocket 等浏览器注入钱包；门户另支持 WalletConnect、BitKeep  
2. 钱包里有一点 **Gas 费对应的主链代币**（公测在 Sepolia 测试网，测试币免费领）  
3. 能访问游戏客户端（ranch.cowgalaxy.com）与门户官网（cowgalaxy.com）的网络环境  

没有钱包？先安装 MetaMask → 创建钱包 → **务必备份助记词**（只保存在自己可控的地方）。

---

## 第一次进入游戏

### 1. 打开游戏并连接钱包

1. 打开传奇牧场游戏页面  
2. 点击连接钱包  
3. 在钱包中确认连接与签名登录  

签名登录不会转账，只是证明「这个地址是你的」。同一账号只允许一处在线，别处登录会把旧会话踢下线。  
游戏与门户、论坛共用同一个钱包地址，三边数据互通。

### 2. 选择语言

游戏支持简体中文、English、繁體中文、한국어，可在登录页或设置中切换（切换后需重启游戏）。

### 3. 绑定星球公会（非常重要）

进入游戏后需要 **选择并绑定一个星球公会**。牛放进牛栏的前提就是已绑定星球。

- 绑定后 **不可自行更换**（被会长踢出或自己持星球卡建会是另外两条路）  
- 之后产奶、战斗等带税收益到账时，按星球 **税率** 自动扣税；税额计入你的 **公会贡献值**  
- 税率由星球类型决定，**会长改不了**：家园星球 20%、拓荒星球 10%、联邦星球成员按母星家园的 20%  

选星球时看：税率（拓荒更轻）、公会活跃度、是否能打公会战（只有家园能报名）。有些公会开启了 **入会审批**，需要先申请、会长通过后再确认加入（见 [08](./08-guild.md)）。  
也可以自己建会：持有家园 / 拓荒星球卡的地址可直接创建公会并成为会长。

### 4. 获得第一头牛

| 方式 | 说明 |
|---|---|
| **公测开服礼包**（当前推荐） | 门户「公测 → 领取公测资产」一键领：拓荒星球、创世牛、成年公牛、成年母牛、小牛、盲盒、全套道具、2000 TIRT、20000 TIRG，见 [17](./17-beta.md) |
| 开盲盒 | 育种研究所开牛牛盲盒；或门户 IGO / 集市活动开盒（几率见 [16](./16-blind-box.md)） |
| NFT 市场购买 | 门户交易市场买 **小牛 / 创世牛**（普通成年牛不能上架，详见 [13](./13-market.md)） |
| 推荐奖励 | 被推荐人每配种 5 次，推荐人得 1 个胚胎盲盒 + 1 张繁殖卡 |

### 5. 把牛放进牛栏

牛必须进入 **牛栏** 才能喂养、繁殖、产奶、战斗。  
初始 2 个栏位，不够在科技研究所花 IRT 扩容，最多 16 格（见 [03](./03-cowshed-and-growth.md)）。

### 6. 选择你的主线

| 你更想… | 建议路线 |
|---|---|
| 稳健产币 | 养 **母牛** → 牛奶厂质押产奶（全服每日 20 万 IRT 产奶池） |
| 战斗竞技 | 养 **公牛** → 斗牛场 PVE / 匹配赛 / 积分赛 |
| 繁殖增值 | 凑齐公母牛 → 育种研究所配种开盒 |
| 社交公会 | 升职、缴税、参加公会战、领福利 |

多数玩家会三条线并行：一两头母牛产奶、一两头公牛打架、有余力再繁殖。

## 主界面大概长什么样

- **上方 / 角落**：IRT、IRG 余额（点余额可跳转 DEX 兑换），头像进入个人中心  
- **场景建筑**：牛栏、牛奶厂、科技研究所、育种研究所、公会、斗牛场、交易市场  
- **侧栏常用**：签到、奖励中心、任务、背包、邮箱、好友 / 聊天  

点建筑进对应玩法；点侧栏处理日常领取与社交。红点提示有可领 / 可做的事。

## 新手推荐顺序（第一周）

1. 登录并绑定星球（或用礼包里的拓荒星球自己建会）  
2. 门户领开服礼包，把牛全部放入牛栏；之后每 24 小时领一次每日补给（草料 + 体力包 + 2000 TIRG）  
3. 小牛喂草料，每天最多涨 15000 成长值，30000 成年；最快 2 天  
4. 母牛进牛奶厂质押（可装徽章），公牛去能量站充能后打 PVE 熟悉卡牌  
5. 每天签到、清任务、领奖励中心；斗牛场次日领胜场宝箱  
6. 顺手攒 **农场经验**（扩栏 / 繁殖 / 养成 / 用药），升到 **2 级** 解锁第一批科技树（见 [03](./03-cowshed-and-growth.md)）  
7. 了解公会福利与公会战；有余力再学配种、升星、科技树

## 测试网与正式环境

- **测试网（公测）**：资产无真实价值，用于体验与找 Bug；公测数据会被记录作为主网空投依据  
- **正式环境**：资产有真实价值，操作前请确认网络、合约与金额  

公测规则、领资产、邀请、反馈入口见 [17 公测指南](./17-beta.md)。

## 安全提醒

- 官方不会要你的助记词 / 私钥  
- 领奖、上架、开盒等需要钱包二次确认时，看清合约与金额再点同意  
- 钓鱼网站很常见：认准官方域名（cowgalaxy.com、ranch.cowgalaxy.com、bbs.cowgalaxy.com）与公告渠道
