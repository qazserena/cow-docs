# 13 NFT 交易市场

交易市场用于买卖 **牛牛、盲盒、星球** 等链上资产（托管挂单，多币种结算以页面为准）。

游戏内「交易市场」建筑通常会跳转到 **门户官网** 的市场页面。

## 你能做什么

| 功能 | 说明 |
|---|---|
| 浏览 / 筛选购买 | 按血统、性别、形态、星级、属性筛选 |
| 上架出售 | 选定资产、定价、授权后上架 |
| 我的挂单 | 查看、下架 |
| 成交记录 | 查看历史买卖 |

平台会收取手续费（费率以合约 / 页面显示为准）。

---

## 筛选逻辑（买家必读）

常见筛选项：

- **血统**：创世 / 普通  
- **性别**：公 / 母  
- **形态**：盲盒 / 小牛 / 成年牛  
- **星级**：0～3 星（一般只对普通成年牛有意义）  
- **属性数值**：基础 / 战斗 / 产奶等区间  

组合规则概念：

- 血统、性别、形态、星级多为「或」关系组合筛选  
- 属性数值条件多为「且」  
- **死亡牛** 会被自动过滤，不会出现在正常列表  

---

## 上架注意

1. 先在钱包中对市场合约完成 **授权（approve）**  
2. 确认网络正确（正式网 / 测试网别搞错）  
3. 质押中、战斗中、繁殖 CD 中的牛可能无法上架  
4. 定价考虑手续费与流动性，避免长期挂死  

---

## 安全提示

- 只通过官方门户入口进入市场  
- 核对合约地址与域名  
- 大额成交前可先小额测试
