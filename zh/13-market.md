# 13 NFT 交易市场

交易市场用于买卖 **牛牛、盲盒、星球** 等链上资产（托管挂单，多币种结算以页面为准）。

游戏内「交易市场」建筑通常会跳转到 **门户官网** 的市场页面。

## 你能做什么

| 功能 | 说明 |
|---|---|
| 浏览 / 筛选购买 | 按血统、性别、形态、星级、属性筛选 |
| 上架出售 | 选定资产、定价、授权后上架 |
| 我的挂单 | 查看、下架 |
| 成交记录 | 查看历史买卖 |

平台会收取手续费（费率以合约 / 页面显示为准）。

---

## 筛选逻辑（买家必读）

常见筛选项：

- **血统**：创世 / 普通  
- **性别**：公 / 母  
- **形态**：盲盒 / 小牛 / 成年牛  
- **星级**：0～3 星（一般只对普通成年牛有意义）  
- **属性数值**：基础 / 战斗 / 产奶等区间  

组合规则概念：

- 血统、性别、形态、星级多为「或」关系组合筛选  
- 属性数值条件多为「且」  
- **死亡牛** 会被自动过滤，不会出现在正常列表  

> 市场里即使有「成年牛」筛选项，**普通成年牛也不能新上架**（见下节）。能买到的「成年」形态，主要是 **创世牛**（创世牛无寿命、始终可交易）。

---

## 哪些牛可以出售

这是链上硬规则，官网详情页没有「出售」按钮时，一般就是这条限制，不是页面坏了。

| 资产 | 能否挂到 NFT 市场 | 说明 |
|---|---|---|
| **普通小牛**（未成年） | 可以 | 详情页会显示「出售」；**以 USDT 挂售时最低 150 USDT**（合约 `Price-288`） |
| **普通成年牛** | **不可以** | 喂大、已成年后无法上架；仍可 **转移** 给其他地址 |
| **创世牛牛** | 可以 | 不受成年状态限制 |
| **盲盒、星球等其它 NFT** | 按品类 | 以详情页按钮和合约为准 |

因此：想交易普通牛，应在 **成年前** 上架或卖掉。成年后只能自用（产奶 / 战斗 / 繁殖）或钱包转出。

---

## 上架注意

1. 先在钱包中对市场合约完成 **授权（approve）**  
2. 确认网络正确（正式网 / 测试网别搞错）  
3. **普通成年牛不能上架**；质押中、战斗中、繁殖 CD 中的牛也可能无法上架  
4. 定价考虑手续费与流动性，避免长期挂死  

---

## 安全提示

- 只通过官方门户入口进入市场  
- 核对合约地址与域名  
- 大额成交前可先小额测试
