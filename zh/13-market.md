# 13 NFT 交易市场

交易市场用于买卖 **牛牛、盲盒、星球** 等链上资产（托管挂单，IRT 或 USDT 结算）。

游戏内「交易市场」建筑会跳转到 **门户官网** 的市场页（cowgalaxy.com/nftMarket）。

## 你能做什么

| 功能 | 说明 |
|---|---|
| 浏览 / 筛选购买 | 按血统、性别、形态、星级、属性筛选；按最新上市 / 最低价 / 最高价排序 |
| 上架出售 | 卡包 → NFT 详情 → 出售：选币种（IRT / USDT）、定价、授权后上架 |
| 我的挂单 | 查看、下架 |
| 成交记录 | 查看历史买卖 |

平台手续费 **2%**（从卖家所得中扣除）。买家成交后 NFT 直接到钱包，牛要再放回牛栏才能用。

---

## 筛选逻辑（买家必读）

- **血统**：创世 / 普通；**性别**：公 / 母；**形态**：盲盒 / 小牛 / 成年牛；**星级**：0 ～ 3 星  
- **属性数值**：基础 / 战斗 / 产奶区间；注意普通牛显示的是已乘星级系数的数值  
- **死亡牛** 会被自动过滤，不会出现在正常列表  

> 市场里即使有「成年牛」筛选项，**普通成年牛也不能新上架**（见下节）。能买到的「成年」形态，主要是 **创世牛**。

---

## 哪些牛可以出售 / 转移

这是链上硬规则，门户详情页没有「出售」按钮时，一般就是这条限制，不是页面坏了。

| 资产 | 挂 NFT 市场 | 钱包直接转账 | 说明 |
|---|---|---|---|
| **普通小牛**（未成年） | 可以 | **不可以** | 以 USDT 挂售时 **最低 150 USDT** |
| **普通成年牛** | **不可以** | **不可以** | 成年后只能自用（产奶 / 战斗 / 繁殖 / 做升星材料） |
| **创世牛** | 可以 | 可以 | 不受成年状态限制 |
| **盲盒、星球卡、皮肤、徽章、兑换券** | 按品类 | 可以 | 拓荒星球卡不可交易 |

普通牛（无论成年与否）的链上转移只允许游戏合约发起，所以钱包 / 门户的「转账」对普通牛会失败。想交易普通牛，应在 **成年前** 上架。

---

## 上架注意

1. 先在钱包中对市场合约完成 **授权（approve）**  
2. 确认网络正确（正式网 / 测试网别搞错）  
3. **普通成年牛不能上架**；在牛栏中（质押 / 战斗 / 喂食 / CD）的牛要先移出牛栏回到钱包  
4. 定价考虑 2% 手续费与流动性，避免长期挂死；下架不收费  

---

## 安全提示

- 只通过官方门户入口进入市场  
- 核对合约地址与域名  
- 大额成交前可先小额测试
