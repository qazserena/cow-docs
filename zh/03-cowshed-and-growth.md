# 03 牛栏与养成

牛栏是牧场的「家」。几乎所有养成行为都以「牛在栏里」为前提。

## 栏位

- 初始 **2** 个栏位，可扩展（当前配置最多约 **16** 个，以游戏内为准）  
- 扩容消耗 **IRT**，价格随次数递增（常见约 500 → 700 → 1000 → … IRT）  
- 扩容入口一般在 **科技研究所** 或牛栏相关界面  

死亡牛仍可能占用栏位，记得及时处理，否则新牛放不进去。

---

## 为什么一定要入栏

牛在栏内才能稳定参与：

- 成长、喂养  
- 繁殖  
- 产奶质押  
- 战斗（成年公牛）  

栏外的牛体力会持续消耗；长时间无人照料有死亡风险（普通牛）。

---

## 喂养（补体力）

1. 打开牛栏，选择目标牛  
2. 使用草料：**普通 / 中级 / 高级草料**（主要花 IRG，消耗后销毁）  
3. 进入进食状态，有倒计时；进食期间通常不能同时做其他活动  

体力用于：成长兑换、产奶质押时长、战斗能量相关消耗等。  
体力不足时，很多玩法会灰掉或提示失败。

---

## 小牛成长为成年牛

- 小牛通过消耗体力转化为 **成长值**  
- 成长值达到目标（常见 30000）后成年  
- 每日通过体力兑换成长值有上限（常见约 10000 / 天）  
- 正常节奏大约数天成年；可用 **成长加速包**：  
  - 成长包 1 / 2：增加一定成长值  
  - 成长包 3：可直接成年（以游戏内说明为准）  

成年后：

- **母牛** → 可进牛奶厂产奶  
- **公牛** → 可进斗牛场战斗  
- **普通成年牛不能再挂 NFT 市场出售**（创世牛不受限）；需要交易请在成年前完成，详见 [13](./13-market.md)  

---

## 农场等级 / 个人牧场等级（1～6 级）

游戏个人中心显示为 **「农场经验」**；门户任务、兑换门槛里常写 **「农场等级 / 牧场等级」**——指的是同一套等级。  
**没有单独的「点升级」按钮**：经验攒满当前档后，会在链上**自动升一级**。

### 升级有什么用

| 显示等级 | 产奶收益系数（约） | 战斗场次加成（约） |
|---|---|---|
| 1 | ×1.00 | ×1.00 |
| 2 | ×1.05 | ×1.10 |
| 3 | ×1.10 | ×1.15 |
| 4 | ×1.15 | ×1.20 |
| 5 | ×1.20 | ×1.25 |
| 6 | ×1.30 | ×1.40 |

另有：个人科技树按等级分批解锁；门户公测邀请 / 兑换券等活动常要求 **农场等级 ≥ 2**。

### 怎么看当前等级与经验

打开 **个人中心**（点头像）→ 查看 **农场经验** 进度条（当前经验 / 本级所需）。

### 升级经验从哪来

| 行为 | 经验 |
|---|---|
| 每次扩栏（买第 3 格起） | +50 / +60 / +80 / +100 / +120 / +150 / +180（随档位递增，每档覆盖两次购买） |
| 每成功繁殖 1 次（得盲盒） | +20 |
| 每把一头幼崽养成成年 | +20 |
| 使用成长加速包（普通 / 中级 / 高级） | +3 / +5 / +9（每个） |
| 使用体力包（普通 / 中级 / 高级） | +3 / +5 / +9（每个） |
| 使用生命药剂（普通 / 中级 / 高级） | +7 / +20 / +38（每个） |

草料喂养本身不加农场经验；成长包若直接把牛喂到成年，还会额外拿到「成年 +20」。

### 升到下一级要多少经验

| 升级 | 所需经验 |
|---|---|
| 1 → 2 | 200 |
| 2 → 3 | 300 |
| 3 → 4 | 450 |
| 4 → 5 | 675 |
| 5 → 6 | 1350 |
| 已满 6 级 | 经验仍可累计，但不再升档 |

### 新手怎么尽快升到 2 级（门户常用门槛）

任选或组合，凑满 **200** 经验即可自动升到 2 级，例如：

1. **扩栏**：连续买几次栏位（前几次约 +50～+60 / 次），再配合繁殖或养成  
2. **繁殖**：成功配种约 **10** 次（10 × 20）  
3. **养成**：把约 **10** 头小牛养到成年  
4. **道具**：用体力包 / 成长包 / 生命药剂补差额  

扩栏在 **科技研究所**；繁殖在 **育种研究所**；养成与用药在 **牛栏**。

### 等级还解锁什么

个人科技树按牧场等级分批解锁：低级先开一部分，中级再开一部分，高级全开。详见 [06 科技研究所](./06-academy.md)。

---

## 养成日常建议

1. 保持栏位够用，别让牛露宿「栏外」  
2. 小牛优先喂满成长；成年后再分流产奶 / 战斗  
3. 普通牛注意寿命，及时用生命药剂  
4. 做任务与签到时，顺便完成「喂养 / 成年 / 扩栏」类目标
