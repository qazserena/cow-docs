# 03 牛栏与养成

牛栏是牧场的「家」。几乎所有养成行为都以「牛在栏里」为前提。

## 栏位

- 初始有少量栏位（常见默认 2 个），可扩展，有上限（常见最多 8 个）  
- 扩容消耗 **IRT**，价格通常随次数递增  
- 扩容入口一般在 **科技研究所** 或牛栏相关界面  

死亡牛仍可能占用栏位，记得及时处理，否则新牛放不进去。

---

## 为什么一定要入栏

牛在栏内才能稳定参与：

- 成长、喂养  
- 繁殖  
- 产奶质押  
- 战斗（成年公牛）  

栏外的牛体力会持续消耗；长时间无人照料有死亡风险（普通牛）。

---

## 喂养（补体力）

1. 打开牛栏，选择目标牛  
2. 使用草料：**普通 / 中级 / 高级草料**（主要花 IRG，消耗后销毁）  
3. 进入进食状态，有倒计时；进食期间通常不能同时做其他活动  

体力用于：成长兑换、产奶质押时长、战斗能量相关消耗等。  
体力不足时，很多玩法会灰掉或提示失败。

---

## 小牛成长为成年牛

- 小牛通过消耗体力转化为 **成长值**  
- 成长值达到目标（常见 30000）后成年  
- 每日通过体力兑换成长值有上限（常见约 10000 / 天）  
- 正常节奏大约数天成年；可用 **成长加速包**：  
  - 成长包 1 / 2：增加一定成长值  
  - 成长包 3：可直接成年（以游戏内说明为准）  

成年后：

- **母牛** → 可进牛奶厂产奶  
- **公牛** → 可进斗牛场战斗  
- **普通成年牛不能再挂 NFT 市场出售**（创世牛不受限）；需要交易请在成年前完成，详见 [13](./13-market.md)  

---

## 个人牧场等级（1～6 级）

牧场等级提升后，会提高 **产奶收益系数** 与 **战斗收益系数**（例如从约 1.05 / 1.1 逐步升到约 1.3 / 1.4，以游戏内为准）。

### 升级经验从哪来（示例规则）

| 行为 | 经验（约） |
|---|---|
| 解锁第 3～8 栏位 | 每档 +50～+80 |
| 每成功繁殖一头 | +20 |
| 幼崽养到成年 | +20 |
| 使用各类体力包 / 成长包 / 生命药剂 | +1～+25 不等 |

升级所需经验随等级提高（例如 200 / 300 / 450 / 675 / 1350…）。

### 等级还解锁什么

个人科技树按牧场等级分批解锁：低级先开一部分，中级再开一部分，高级全开。详见 [06 科技研究所](./06-academy.md)。

---

## 养成日常建议

1. 保持栏位够用，别让牛露宿「栏外」  
2. 小牛优先喂满成长；成年后再分流产奶 / 战斗  
3. 普通牛注意寿命，及时用生命药剂  
4. 做任务与签到时，顺便完成「喂养 / 成年 / 扩栏」类目标
