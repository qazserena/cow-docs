# 术语对照

| 术语                    | 含义                 |
| --------------------- | ------------------ |
| 传奇牧场                  | 本游戏名称              |
| 牛宇宙 / CowGalaxy       | 游戏世界观所属宇宙          |
| IRT                   | 主代币                |
| IRG                   | 游戏金币               |
| 创世牛                   | 高稀有永恒寿命牛 NFT       |
| 普通牛                   | 可升星、有寿命的主流牛 NFT    |
| 牛栏 / CowShed / Stable | 放置与养成牛的设施          |
| 农场等级 / 牧场等级 / 农场经验 | 个人中心「农场经验」对应的 1～6 级；扩栏、繁殖、养成、用药加经验，满档自动升级；影响产奶/战斗加成与科技解锁。详见 [03](../../yang-cheng-yu-zhuan-qian/03-cowshed-and-growth.md) |
| 牛奶厂 / Factory         | 质押母牛产奶挖 IRT        |
| 育种研究所                 | 配种、开盒、借配           |
| 科技研究所 / Academy       | 商店、扩栏、升星、科技树       |
| 斗牛场 / Arena           | PVE / 匹配 / 积分赛     |
| 星球 / 公会               | 玩家所属组织，绑定后一般不可换    |
| 家园 / 联邦 / 拓荒星球        | 三类星球               |
| 公会战 / GVG             | 公会间守护者对抗           |
| 守护者                   | 公会战中的公会 BOSS 单位    |
| 奖励中心                  | 汇总领取各类奖励的界面        |
| 盲盒 / 胚胎盒              | 开出牛或碎片的 NFT 盒      |
| 算力                    | 产奶分奖权重             |
| 贡献值                   | 缴税等行为累计的公会贡献       |
| Gas                   | 链上交易手续费            |
| 授权 / Approve          | 允许合约动用你的代币或 NFT    |
| 门户 / Portal           | 官网活动与市场站点          |
| IGO                   | 限时创世盲盒发售           |
| Banker 签名             | 服务端签名后玩家才能领的某些链上奖励 |
